Task curent
-----------
Tema globala Harry Potter, adaugata langa Classic, Retro, Medieval, Matrix,
Disco si Boho.

Analiza si arhitectura
----------------------
- Aplicatia nu avea o pagina Settings si nici un mecanism global de tema.
- Exista deja endpoint-ul generic per utilizator /api/ui-preferences/{key};
  acesta a fost reutilizat, deci nu a fost necesar un endpoint backend nou.
- Tema este reprezentata prin tokenuri CSS globale, nu prin copii separate ale
  fiecarei pagini. Astfel, o componenta noua poate folosi automat aceeasi tema.
- Stilurile vechi contin multe culori hardcodate; a fost adaugat un strat de
  compatibilitate pentru shell, wrappers, carduri, tabele, formulare si tabs.
- Terenurile, heatmap-urile, fetele, stemele si culorile semantice ale
  succesului/erorilor nu sunt recolorate fortat.

Ce a fost implementat
---------------------
- Ruta noua /settings, accesibila din sidebar-ul Manager si bara Chairman.
- Sapte carduri mari cu preview, descriere, paleta si mini-interfata.
- Aplicarea temei este instantanee la click, fara buton Save separat.
- Buton Restore Classic si confirmare vizuala dupa salvare.
- ThemeService global cu validare stricta inclusiv pentru harry-potter.
- Preferinta este salvata local si sincronizata in user_ui_preferences sub
  cheia appearance.theme.
- Preferinta per utilizator este reincarcata dupa restaurarea sesiunii.
- Un script minimal din index.html aplica tema locala inainte de bootstrap,
  eliminand flash-ul temporar al temei Classic la refresh.

Teme
----
- Classic: designul FM modern existent, dark si data-first.
- Retro: navy/purple, cyan si magenta, font monospace, colturi drepte,
  umbre pixelate si grila discreta de computer din anii 1990.
- Medieval: maro inchis, pergament, alama, rosu heraldic, font serif si
  suprafete inspirate de lemn/documente regale.
- Matrix: negru si verde fosforescent, monospace, colturi drepte, glow subtil,
  fundal terminal si scanlines globale.
- Disco: violet profund, roz electric si cyan, panouri lucioase, gradiente,
  glow de scena si o animatie atmosferica discreta.
- Animatia Disco respecta prefers-reduced-motion si este dezactivata automat
  pentru utilizatorii care solicita miscari reduse.
- Boho: fundal brun cald, teracota, nisip si verde salvie, colturi organice,
  font editorial si texturi textile discrete, fara animatii decorative.
- Harry Potter: bleumarin nocturn, burgundy, pergament si auriu, font serif,
  lumina de lumanare si particule stelare create exclusiv prin CSS.
- Marcajul temei active foloseste acum numele din definitie, astfel incat
  identificatorii compusi precum harry-potter nu mai apar cu cratima in UI.

Acoperire globala
-----------------
- Body, app-root, pagina rutata si shell-ul Manager/Chairman.
- Sidebar, active links, hover, separatoare si top command bar.
- Titluri, fonturi, page headers, tabs si active states.
- Carduri, panouri, modale, tabele, randuri si formulare.
- Settings foloseste acum un grid auto-responsive pentru toate cele sapte teme,
  cu doua coloane pe tableta si una pe mobil.
