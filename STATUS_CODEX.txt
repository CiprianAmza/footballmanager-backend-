Task curent
-----------
Extinderea paginii Assistant Manager cu informatii tactice, statistice si
analize de tip Opta.

Ce a fost implementat
---------------------
- Noua vedere implicita Season Performance, cu rezultate vs Expected Points,
  goluri vs xG, goluri primite vs xGA, xG difference/90 si conversie.
- Assistant Verdict transforma abaterile statistice in recomandari explicabile:
  semnal, dovada, actiune recomandata si nivel de incredere.
- Chance Creation: xG/sut, big chances, suturi din careu, touches in box,
  distanta medie si provenienta datelor observate/modelate.
- Possession & Progression: field tilt, progressive passes/carries, funnel
  pase -> progresie -> ultima treime -> careu -> suturi.
- Pressing & Defence: PPDA-like, rata presiunilor reusite, recovery time,
  high turnovers, xGA/sut si dueluri. PPDA este etichetat explicit PROXY.
- Set Pieces: xG/corner pentru si contra, ponderea fazelor fixe in xGA,
  recuperarea mingii a doua si insight-ul principal.
- Clasamente scurte pentru liderii progresiei si pressingului, cu link direct
  spre pagina jucatorului.
- Scurtaturi catre Tactics, Squad, Training si Data Hub.
- Design responsive, compatibil cu toate temele, cu tab-uri sticky pe mobil.

Corectii incluse
----------------
- Formation foloseste acum cheile reale `recommended` si `allFormations`.
- Pre-match briefing citeste corect obiectele imbricate formation,
  lineupConcerns si opponentAnalysis.
- Opposition afiseaza lista reala positionAnalysis, puterea comparata,
  punctele slabe si punctele forte.
- Iconurile de risc recunosc tipurile backend INJURED, LOW_MORALE,
  LOW_FITNESS, CONTRACT_EXPIRING si WANTS_TRANSFER.
- Fiecare endpoint statistic poate esua independent; rapoartele disponibile
  raman vizibile si pentru salvarile mai vechi.
