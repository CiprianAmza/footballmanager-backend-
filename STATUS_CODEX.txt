Task curent
-----------
Modul Opta-style Shot & Chance Creation in Data Hub.

Ce a fost implementat in motor/backend
--------------------------------------
- Entitate ShotEvent: un eveniment persistent pentru fiecare sut al meciului.
- Fiecare sut contine pozitie normalizata, minut, distanta, unghi, destinatie
  in poarta, rezultat, xG, xGOT, situatie, tipul creatiei, canal, body part,
  big chance, presiune, interior/exterior careu si calitatea sursei.
- MatchStatsService genereaza si persista automat ledger-ul de suturi dupa
  salvarea oricarui tip de meci: legacy, canonical, instant sau live.
- Meciurile istorice fara ShotEvent sunt reconstruite determinist in memorie,
  fara scrieri ascunse in baza de date si sunt marcate MODELED.
- Suma xG a evenimentelor este exact egala cu xG oficial din MatchStats.
- xGOT este calculat numai pentru suturile pe poarta si foloseste pozitia
  finala in cadrul portii, plus calitatea initiala xG.
- Shooting Goals Added = xGOT - xG al suturilor pe poarta.
- Goals Prevented pentru portar = xGOT primit - goluri primite.
- A fost corectata asocierea neverosimila a mai multor goluri cu xG aproape zero;
  golul unic dintr-un sut cu xG mic ramane posibil.

Ce ofera endpoint-ul Data Hub
-----------------------------
- Shot map complet cu marimea punctului proportionala cu xG.
- xG total, xG/sut, xGOT, Shooting Goals Added si Goals Prevented.
- Suturi din careu / afara, big chances, distanta si unghi mediu.
- Suturi sub presiune si touches in opposition box.
- xG din open play, corner, lovitura libera si penalty.
- Suturi create dupa cross, through ball, recovery, combinatie, actiune
  individuala sau faza fixa.
- Ocazii create pe stanga, centru si dreapta.
- Secventele care produc cele mai multe suturi.
- Chance creation funnel: posesii -> ultima treime -> careu -> suturi -> goluri.
- Indicator explicit OBSERVED/MODELED; pasii funnel dinaintea sutului sunt
  marcati ca estimari derivate din statisticile meciului.

Ce a fost implementat in frontend
---------------------------------
- Tab nou Shot & Chance Creation in Data Hub.
- Shot map pe teren, cu legenda Goal/Saved/Wide/Blocked/Big Chance.
- KPI-uri de calitate si executie, profilul suturilor, funnel vizual,
  distributii pe sursa/tip/zona si top secvente.
- Layout responsive si stari Error/Empty.
