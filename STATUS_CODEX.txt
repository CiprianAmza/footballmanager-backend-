Filtre si coloane salvate per utilizator.

Ce a fost implementat
---------------------
- A fost adaugat un API autentificat pentru preferinte UI per utilizator.
- Preferintele sunt izolate dupa utilizator si cheie de tabel si sunt salvate in baza de date.
- Frontend-ul foloseste si un cache local per utilizator pentru functionare offline si fallback.
- Transfer Market salveaza pozitia, valoarea minima/maxima si sortarea aleasa.
- A fost adaugat un selector de coloane cu 7 coloane configurabile.
- Coloana Name ramane obligatorie; toate celelalte pot fi ascunse sau reafisate.
- Numarul coloanelor active este afisat direct in butonul Columns.
- Reset filters and columns sterge preferinta din cont si restaureaza valorile implicite.
- Preferintele sunt validate in backend (cheie sigura, obiect JSON si limita de dimensiune).
