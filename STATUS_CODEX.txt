Task curent
-----------
Afisarea corecta a retrogradarii si a calificarilor europene in clasamentul
unei competitii, inclusiv ruta rezervata castigatoarei cupei nationale.

Ce a fost implementat
---------------------
- Informatia Relegation este afisata numai daca in aceeasi natiune exista o
  liga la tier-ul imediat inferior.
- Pragul de retrogradare nu mai este hardcodat la pozitia 18; este calculat
  din numarul real de echipe, pentru ultimele doua pozitii.
- Backend-ul produce un context exact per competitie si sezon, inclusiv pentru
  sezoanele istorice.
- Fiecare echipa primeste explicit una dintre rutele LOC sau STARS_CUP, in loc
  ca frontend-ul sa presupuna ca toate locurile Stars Cup sunt consecutive.
- Castigatoarea cupei nationale primeste badge-ul CW si ruta Stars Cup.
- Daca castigatoarea cupei este deja calificata in League of Champions, LoC are
  prioritate, iar locul rezervat cupei este realocat primei echipe eligibile.
- Aceeasi realocare se aplica daca detinatoarea cupei are deja ruta Stars Cup
  prin pozitia din campionat.
- Legenda clasamentului afiseaza numele castigatoarei cupei si destinatia sa
  europeana; marcajele disponibile sunt C, CW, LoC, SC si R.
- Contextul este reincarcat la schimbarea sezonului si dupa evenimente care
  actualizeaza clasamentul, astfel incat finala cupei apare fara refresh manual.

Backend
-------
- Endpoint nou:
  GET /competition/leagueQualification/{competitionId}/{season}
- Raspunsul include hasLowerTier, relegationFrom, locSpots, starsCupSpots,
  castigatoarea cupei si lista calificarilor exacte per echipa.
- Castigatoarea istorica este citita din CompetitionHistory.
- Pentru sezonul curent este acceptat un castigator numai daca exista rezultatul
  rundei finale calculate din numarul real de participante; o semifinala jucata
  nu este confundata cu finala.
