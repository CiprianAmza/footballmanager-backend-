Task curent
-----------
Extinderea analizei Underlying Performance si publicarea ei pe pagina competitiei.

Ce a fost implementat
---------------------
- Endpoint nou cu analiza tuturor echipelor dintr-o competitie si un sezon.
- xG difference per 90 pentru intregul sezon.
- Rolling xGD/90 pentru ultimele 5, 10 si 20 de meciuri, cu esantionul real afisat.
- Procentul meciurilor in care echipa a produs xG mai mare decat adversarul.
- Rezultatele in meciurile echilibrate: W-D-L, puncte, xPts si xGD/90.
- Meci echilibrat este definit transparent ca |xG - xGA| <= 0.25.
- Performanta contra Top 4, Top Half si Lower Half: W-D-L, puncte, xPts si xGD/90.
- Grupele valorice sunt calculate din clasamentul sezonului selectat; Top Half include Top 4.
- Luck index este diferenta dintre puncte/meci si xPts/meci; este afisata si
  diferenta totala de puncte fata de asteptari.
- Clasamentul analitic include si echipele inscrise care nu au jucat inca.
- Pagina competitiei are un tabel nou cu randuri expandabile pentru toate segmentele.
- Sectiunea este disponibila atat pentru ligi, cat si pentru cupe.
- Exista stari Loading, Error si Empty si explicatie completa a metodologiei.
