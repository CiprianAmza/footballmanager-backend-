STATUS CODEX
============

Ultima actualizare: 2026-08-06
Status: FINALIZAT

Task curent
-----------
Redesign vizual agresiv al /match-centre2 pentru a functiona ca un match
viewer TV full-screen, nu ca un dashboard modern cu trei carduri.

Ce s-a schimbat
---------------
- Match Centre 2 ocupa intregul viewport si elimina marginile aplicatiei pe
  durata transmisiunii.
- Terenul ocupa exact aproximativ 70% din latimea desktopului si toata
  inaltimea utila dintre HUD si comentariu.
- Headerul competitiei are 27px, scoreboardul 45px si controalele media 29px.
- Scorul este prezentat intr-o singura banda TV compacta, cu numele echipelor
  integrate in aceeasi grafica.
- Statisticile din stanga sunt un panou glass ingust, semitransparent, peste
  atmosfera stadionului; Match Facts si Squad Fitness raman interactive.
- Zona dreapta nu mai contine text explicativ sau un card informational. Este
  decor de stadion, cu tribuna, reflectoare si bug TV discret.
- Controalele 2D/3D, discs/sprites, manual/auto, sunetul, viteza, Skip si
  substitutions sunt pastrate intr-o bara media foarte compacta.
- Comentariul este o singura banda neagra de broadcast sub teren, cu text
  galben si actiunea Replay pastrata.
- Terenul nu mai are margini, card, radius sau padding si foloseste implicit
  camera clasica 2D cu discuri mici, apropiata de referinta.
- Replay zoom, synthetic extra time, penalty shootout, substitution modal si
  actiunile post-match continua sa foloseasca motorul existent.

Raport vizual desktop
---------------------
- Coloana statistici: 15vw.
- Teren: 70vw.
- Atmosfera stadion / broadcast: 15vw.
- HUD total deasupra terenului: 101px.
- Comentariu broadcast: 28px.

Compatibilitate
---------------
- Modificarea este izolata in /match-centre2.
- /live-match si celelalte prezentari ale motorului nu primesc noul skin.
- Contractele backend si starea meciului nu au fost modificate.
- La sub 980px, viewerul trece intr-un layout orizontal scrollabil, pastrand
  terenul utilizabil in loc sa il comprime pana devine ilizibil.
