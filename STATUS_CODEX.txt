Task curent
-----------
Set Pieces Hub separat in Data Hub, cu analiza fazelor fixe pentru/contra,
benchmark de competitie, jucatori periculosi, vulnerabilitati si insights.

Ce a fost implementat in backend
--------------------------------
- Ledger persistent SetPieceEvent, cu fiecare faza fixa a ambelor echipe.
- Tipuri: CORNER, DIRECT_FREE_KICK, INDIRECT_FREE_KICK, PENALTY si LONG_THROW.
- Pentru fiecare eveniment: delivery style (short/inswinging/outswinging), zona
  livrarii, primul contact, recuperarea mingii a doua, rezultat si xG.
- Numerele de cornere si lovituri libere se reconciliaza cu MatchStats.
- Penalty-urile si xG-ul fazelor fixe se reconciliaza cu ShotEvent.
- Salvare automata odata cu MatchStats; carierele istorice sunt reconstruite
  determinist in memorie, fara mutatii la GET.
- Endpoint nou:
  /stats/team/{teamId}/season/{seasonNumber}/set-pieces

Ce returneaza agregarea
----------------------
- Cornere pentru/contra, suturi si goluri dupa corner.
- xG total si xG per corner pentru/contra.
- Short vs inswinging vs outswinging.
- Zone near post, centre, far post si edge of box.
- Primul contact si second-ball recovery.
- Lovituri libere directe/indirecte, penalty-uri si aruncari lungi.
- Executantii si tintele aeriene cele mai periculoase, folosind executantii
  configurati in tactica si atributele tehnice/aeriene ale lotului.
- Vulnerabilitati de marcaj zonal/individual pe zone, cu incidente si xGA.
- Competitia principala aleasa automat dupa cele mai multe meciuri ale echipei.
- Media competitiei pentru cornere/meci si xG/corner, plus diferentele echipei.
- Insights generate din date; exemplu real din model:
  "X% of total xGA comes from corners delivered to the far post".

Corectitudinea datelor
----------------------
- Counts: OBSERVED_COUNTS din MatchStats.
- xG: reconciliat cu ShotEvent.
- Delivery, zone, first contact, second ball si marking: marcate explicit
  MODELED_DELIVERY_FROM_MATCH_STATS pana cand motorul persista aceste actiuni.
- Niciun insight nu este hardcodat cu un procent fix.

Ce a fost implementat in frontend
---------------------------------
- Tab nou Set Pieces Hub in Data Hub.
- KPI-uri, insights, delivery breakdown, attacking/defensive zones.
- First contact, second-ball recovery si toate tipurile de faze fixe.
- Top jucatori periculosi cu link direct la profil.
- Marking vulnerabilities si comparatie cu media competitiei.
- Layout responsive.
- Stilurile au fost compactate pentru a nu depasi bugetul CSS al componentei;
  nu a fost relaxat niciun prag de build.
