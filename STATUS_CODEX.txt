Task curent
-----------
Command palette cu scurtaturi de tastatura.

Ce a fost implementat
---------------------
- Paleta de cautare a fost transformata intr-un command palette complet.
- Comenzile Continue, Save game si Load game pot fi cautate si executate din paleta.
- Cmd/Ctrl+S salveaza cariera, iar Cmd/Ctrl+O deschide selectorul pentru Load game.
- Cmd/Ctrl+K, / si ? deschid paleta; Escape o inchide.
- Navigarea rapida foloseste secvente de doua taste: G apoi H/I/S/T/M/R etc.
- Fiecare actiune si pagina afiseaza shortcut-ul disponibil direct in rezultat.
- Rezultatele sunt grupate in Commands, Pages, Players, Clubs si Competitions.
- Sagetile sar peste actiunile temporar indisponibile; Enter executa rezultatul selectat.
- Continue si Load sunt dezactivate automat in timpul simularilor si dialogurilor critice.
- A fost adaugat feedback vizual temporar dupa apasarea tastei G.
