Task curent
-----------
Mesajul primit in Inbox dupa meci este acum un raport editorial complet, nu
doar titlul cu scorul.

Backend
-------
- Mesajul post-meci salveaza o referinta canonica spre partida exacta:
  competitie, sezon, etapa, gazde si oaspeti.
- Textul mesajului este narativ si include rezultatul, competitia si marcatorii.
- Marcatorii sunt filtrati acum si dupa competitie + etapa; doua partide cu
  acelasi adversar si acelasi scor nu mai pot fi confundate.
- Referinta foloseste campul existent `deduplicationKey`, deci nu este necesara
  o schimbare de schema si save/load ramane compatibil.
- Mesajele post-meci deja existente sunt asociate la citire cu partida stocata,
  folosind sezonul, etapa, echipele si scorul. Asocierea se face numai daca este
  unica; datele vechi din cariera nu sunt rescrise.

Frontend
--------
- Inbox incarca raportul din endpointul canonic `/match/report/...`.
- Mesajul afiseaza articolul, scorul final, shots, xG, possession, omul
  meciului, evenimentele importante si sursa competitiei.
- Sunt disponibile linkuri directe catre raportul complet, ambele cluburi si
  profilul omului meciului.
- Mesajele vechi si toate celelalte categorii raman pe randarea text standard.
