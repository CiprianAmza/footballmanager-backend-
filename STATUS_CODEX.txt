Task curent
-----------
Underlying Performance ca prima pagina vazuta de manager in Data Hub.

Ce a fost implementat
---------------------
- Data Hub se deschide implicit pe noul tab Underlying Performance.
- Sunt afisate cinci comparatii: puncte vs Expected Points, goluri vs xG,
  goluri primite vs xGA, diferenta de conversie si xG difference / 90.
- Expected Points este calculat pentru fiecare meci din probabilitatile Poisson
  generate de xG si xGA; rezultatul sezonului este suma valorilor per meci.
- Statisticile sunt agregate corect din perspectiva echipei, acasa si in deplasare.
- Sunt afisate diferentele fata de model, nivelul de incredere si metodologia.
- Ultimele zece meciuri ofera comparatia puncte reale vs xPts si scor vs xG.
- Exista o stare explicita inainte de primul meci cu date statistice.
- Frontend-ul poate deriva temporar aceleasi valori din endpoint-ul Data Hub
  existent daca backend-ul nou nu a fost inca restartat.
- Layout-ul este responsive pentru desktop, tableta si mobil.
